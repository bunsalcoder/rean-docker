Lab: labs/09-production

Checklist before “real” deploy

  1. Pin versions — postgres:16-alpine, not postgres:latest. Early labs use series tags (redis:7-alpine, node:22-alpine, nginx:1.28-alpine). CRITICAL-gated / production-minded labs pin digests (FROM node:22-alpine@sha256:… in Labs 05, 08 slim, 09, 12, and 13; Postgres/Redis in Lab 13 Compose — Lab 05 Compose still floats those tags on purpose). Chapter 15 explains tag vs digest.
  2. Non-root user — USER node or custom UID
  3. Read-only root filesystem where possible (--read-only + writable tmp mounts)
  4. Healthchecks — Alpine Node images often have no wget/curl. Probe with the same Node runtime as the app:
HEALTHCHECK --interval=15s --timeout=3s --start-period=5s --retries=3 \
  CMD node -e "fetch('http://127.0.0.1:3000/health').then(r=>process.exit(r.ok?0:1)).catch(()=>process.exit(1))"

healthcheck:
  test:
    [
      "CMD",
      "node",
      "-e",
      "fetch('http://127.0.0.1:3000/health').then(r=>process.exit(r.ok?0:1)).catch(()=>process.exit(1))",
    ]
  interval: 15s
  timeout: 3s
  retries: 3
  start_period: 5s
  1. Resource limits — Compose V2 (docker compose) applies deploy.resources on a single node. You do not need Swarm or the old mem_limit / cpus keys.
deploy:
  resources:
    limits:
      cpus: "0.50"
      memory: 256M
  1. Restart policy
restart: unless-stopped
  1. Init process — init: true (or docker run --init) so PID 1 reaps zombies and forwards SIGTERM from docker stop. Pair with exec-form CMD and a graceful shutdown in the app.
init: true
  1. Logging — don’t log secrets; ship logs to a collector; cap Docker json-file logs so a noisy app cannot fill the disk.
logging:
  driver: json-file
  options:
    max-size: "10m"
    max-file: "3"

  1. One process per container (guideline) — app in one, db in another; use Compose/K8s to compose them.

  2. Immutable images — rebuild and redeploy; don’t “hotfix” running containers.

  3. Publish on localhost when a reverse proxy will terminate TLS — 127.0.0.1:3000:3000 so the API is not advertised on every host interface. Lab 09 and Lab 12’s prod Compose do this.

  4. Drop Linux capabilities — cap_drop: [ALL] (or docker run --cap-drop ALL) so the process cannot gain kernel privileges it does not need. Pair with no-new-privileges.

Restart policies

Policy Behavior
no Never restart
always Always restart
on-failure Restart on non-zero exit
unless-stopped Always, except if you manually stopped it
