Lab: labs/11-security

Compare whoami on a non-root image vs Alpine, build with BuildKit --secret (nothing in docker history), and optionally scan with Trivy. Lab 04 already showed the leaky ENV anti-pattern.

  1. Don’t run as root in production containers when avoidable.
  2. Scan images for CVEs (docker scout, Trivy, Grype).
  3. Minimal base images + multi-stage.
  4. Never commit secrets; never ENV PASSWORD=... with real secrets in Dockerfile.
  5. Pin digests for critical supply-chain control:
docker image inspect alpine:3.22 --format '{{index .RepoDigests 0}}'
# Labs 05/08(slim)/09/12/13 pin FROM node:22-alpine@sha256:…; Lab 13 Compose pins Postgres/Redis too.

docker pull nginx@sha256:...
  1. Drop capabilities / use security options when needed (--cap-drop ALL).
  2. Keep Engine updated.
  3. Treat the Docker socket as root — mounting /var/run/docker.sock into a container is nearly equivalent to giving that container root on the host.
